# 🐍 Month 1 with Python: From Zero to CLI Apps
**Crafted by Zayaan**

> *"The best way to learn programming is to write a lot of broken code until it stops breaking."*

Welcome to my repository! This is a showcase of my very first month learning Python. I went from learning basic syntax to writing full command-line games, building OOP systems, and managing persistent JSON file databases.

---

## ⚡ What's Inside?

| # | Project | Description | Key Tech / Concepts |
|---|---|---|---|
| 01 | **`first calculator.py`** | My baseline CLI calculator for arithmetic operations. | `input()`, operators, loops |
| 02 | **`Advance CALC.py`** | Upgraded calculator built to handle user errors gracefully without crashing. | `try / except`, validation |
| 03 | **`guess the number.py`** | Classic number guessing game with live higher/lower feedback and guess counting. | `random`, state tracking |

## 🚀 Key Takeaways From Month 1

* **Object-Oriented Programming:** Moving from loose global variables to encapsulated classes (`class Bank_acc`).
* **Data Persistence:** Using `json.dump()` and `json.load()` to make CLI apps remember user state.
* **Defensive Coding:** Wrapping user inputs in robust `try/except` blocks to eliminate unexpected crashes.
* **Code Refactoring:** Learning to rewrite working code so it looks cleaner, runs faster, and reads better.
